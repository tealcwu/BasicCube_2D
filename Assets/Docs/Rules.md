### 项目规范
  1. 在项目根目录或 `Assets` 下建立以下层级：
     * `Assets/Scenes/Tasks/`（存放 14 个独立关卡场景）
     * `Assets/Scripts/Tasks/`（存放 14 个关卡对应的控制器）
     * `Assets/Scripts/Common/`（存放公共工具、Gizmos 绘制辅助、基类）
     * `Docs/Articles/`（存放 14 篇图文教程 Markdown）
     * `Docs/VideoScripts/`（存放视频分镜脚本与逐字稿）
  2. 检查或更新项目根目录下的 `.gitignore`：
     * 确认包含 `RawFootage/` 或本地大体积视频素材目录，防止大文件（.mp4/.mov）误提交进 Git。

#### 统一视听标准与 Unity 项目环境
* **目标**：保证录制出来的所有视频片段、动图色调一致、画幅比例统一，避免后期拼接突兀。
* **执行指引**：
  1. **Game 视图分辨率**：在 Unity Game 窗口中添加并固定选择 `1920x1080` (16:9) 分辨率预设。
  2. **物理与渲染帧率**：
     * `Project Settings -> Time`：检查 `Fixed Timestep`（推荐设为标准的 `0.02`，即 50Hz，或者 `0.0166667` 即 60Hz），保证物理步长稳定。
  3. **视觉色彩基准（设计系统建议）**：
     * **相机背景色**：推荐使用深灰暗黑风（Hex `#1E1E1E` 或 `#242424`），高对比度且不易引起视觉疲劳。
     * **主角方块色**：鲜明的亮色（如纯白 `#FFFFFF` 或青色 `#00F0FF`）。
     * **地面颜色**：低饱和度中灰（如 `#3A3A3A`）。

#### 确立教学代码规范（“翻车开关”模式）
* **目标**：让代码天然具备“教学演示属性”，无需为了录视频来回改代码。
* **执行指引**：
  * 后续每个 Task 的控制器脚本，统一遵循以下代码模式：
    ```csharp
    [Header("教学对比开关")]
    [Tooltip("勾选使用商业级正解实现，取消勾选使用常见新手反面写法")]
    [SerializeField] private bool useCorrectApproach = false;
    ```
  * 这样你在 Inspector 检查器中随手一点，就能在运行状态下无缝对比两种手感，方便 OBS 顺畅录制。
