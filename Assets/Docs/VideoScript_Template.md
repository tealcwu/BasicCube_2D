视频分镜脚本模板

1. 设计哲学：“黄金前 3 秒抓人 + 双栏分镜（画面操作 vs 逐字解说）”

视频节奏必须紧凑，前 3 秒定留存。视频脚本最好采用影视工业标准的双栏分镜表（一列记录屏幕画面与操作，一列记录解说旁白和音效），方便录制时对照操作、配音时对照读稿。


# 视频脚本：【第 X 期】视频全名

* **时长预估**：60 秒 ~ 90 秒（短视频） / 3~5 分钟（小专题）
* **核心看点**：本期解决的核心痛点。
* **录制环境准备**：OBS 1080P/60FPS、打开 Keyviz（按键回显）、切换到指定场景。
